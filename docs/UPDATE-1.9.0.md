# 1.9.0 更新与使用

## 使用入口

| 功能 | 入口 |
| --- | --- |
| 长期记忆 | 输入“记住：我喜欢简洁回答”，在“手记 → 记忆”查看、修改或删除 |
| 待办 | 输入“添加待办：核对引文”，在“手记 → 任务清单”管理 |
| 停止回应 | 点击“停止”，或直接发送下一条消息 |
| 窗口观察 | 点击聊天中的观察状态查看最近检查详情；更多菜单可开启/暂停、跟随窗口或绑定应用 |
| 执行记录 | 点击任务卡，或“手记 → 执行记录” |
| 当天阅读 | “手记 → 读书手记”，查看来源、节选、译文、感想和留言 |
| 翻译/摘要 | “更多 → 读书与任务 → 文字与学习工具”，可导入 PDF / 图片 |
| 天气/抽签/专注 | 直接输入“天气”“抽签”“专注” |

## 状态含义与限制

“送入回答上下文”表示该版本记忆确实加入过模型输入，不保证模型引用；旧版没有调用追踪，因此缺少记录不等于过去从未使用。旧数据迁移保留原文和时间，不虚构来源。记忆不是聊天历史，每日 4 点清理读书记录不会删除它。自动提炼所有闲聊、跨设备记忆同步不在本次实现范围。

窗口观察依赖系统录屏许可和可用的模型服务，识别的是可见文字，不能据此声称理解视频画面。任务卡完成表示宿主操作返回成功，待办清单仍需按实际情况标记。取消本地回应不会撤销已经发生的外部操作。

当日边界为 Asia/Tokyo 04:00；应用未运行时不执行清理，下次启动会清理过期阅读。最多保留 30 条阅读节选、100 条留言，阅读进度另存。不会把私人阅读历史纳入仓库。

## 验证

本机已验证：连续消息替换、停止请求、已保存记忆被用于回答、任务卡与独立观察状态、自动截图/OCR到模型回应、原有日语播放完成。数据迁移、更正后调用版本、凌晨4点读书与留言清理均有隔离测试。编译/签名检查与 Python 回归测试在上传前执行。每日首次问候与今日签保留沿用此前本机测试结果，未等待真实跨日重新测试。

更新后 macOS 可能需要重新关联原有录屏许可；设置开关开启不等于运行中的新版本已取得许可。运行时状态会显示失败原因。
