# 配置与隐私

运行数据位于 `~/Library/Application Support/LunaGuardian/`，不应提交到 Git。模型配置见 `examples/model.example.json`，密钥仅在本机保存，设置界面不会回显。切换供应商前检查目标 URL；客户端拒绝带用户名密码的 URL，并禁止自动重定向请求以避免凭据跟随跳转。

`extra_body` 可放供应商专用参数，例如 Qwen 的 `chat_template_kwargs: {enable_thinking: false}`。通用请求不强加此参数；改变服务地址会移除旧参数。并非每个兼容接口都支持相同参数，需按服务端能力配置。

## 人设

`src/persona_luna.txt` 来自既有 LunaCompanion 的 `runtime/persona_luna.txt`，保留樱小路露娜身份、沉稳傲娇、善意理解、诚实和不编造记忆的约束。原有“只说一句”改为正常聊天长度；语音改写仍受任务长度限制。所有聊天、读屏、阅读感想、生活规划共用该系统提示词。

## 本地语音

动态日语语音依赖已有 GPT-SoVITS runtime，默认位置：`~/Library/Application Support/LunaCompanionMac/runtime`。该目录的 Python 环境、GPT/SoVITS 模型、参考音频须自行准备；仓库不包含模型权重。没有此环境时不能声称动态语音可开箱即用。固定语音与字幕存于 assets/voices。

## Codex

`src/handoff.py` 默认寻找已安装 ChatGPT.app 内的 Codex CLI，需已登录。具体路径随宿主版本可能变化。交接在本机独立任务目录运行，最多 10 分钟；不会向当前聊天注入消息，也不会自动获得整个磁盘写权限。

## 权限与数据流

屏幕录制用于当前窗口截图、本地 OCR；不保存截图。识别到的最多 1200 字及应用名会发到所配置的 LLM 服务。聊天历史也会随对话发出，因此只有信任的服务才应填入配置。读书正文节选发往相同服务。位置仅用于城市天气；无移动轨迹。系统照看不等于杀毒软件。

macOS 录屏、定位等权限由系统控制。本项目使用临时签名，重新构建或替换 app 后可能需要重新授予录屏权限；没有绕过系统授权的功能。

## 素材

樱小路露娜来自《近月少女的礼仪》。动作图为此私人项目生成/整理；原有角色素材及语音模型不声明为原创或自由许可。本仓库未给第三方素材授予新的许可。

## 上下文、记忆与维护

对话默认最近 3 轮，总计最多约 2400 字；单条历史最多 800 字。每天本机时间 04:00、或闲置 6 小时后重置模型上下文，保留可见聊天记录（最近 100 条）、长期记忆和任务。应用休眠或未运行时，维护在恢复运行后触发，不声称休眠中也精确执行。

本机当前日期、时间和 UTC 偏移每次提供给模型，无需额外权限。记忆和任务存于本机 `notebook.sqlite`；只保存用户明确要求记住或在界面添加的内容。最多提取 6 条、1400 字相关记忆和未完成任务进入聊天，按简单文字匹配排序，不运行向量模型。没有自动从屏幕内容建立个人记忆。

工具运行摘要独立存于 `tool-events.json`，不记录请求参数或正文，后台清理，聊天不展示原始工具日志。`maintenance.py` 借用既有巡检定时器，无需额外常驻 Python 服务。Codex App 每日检查是本机当前任务上的自动化，不属于下载源码后自动安装的功能。
