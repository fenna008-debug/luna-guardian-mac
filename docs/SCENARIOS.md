# 使用场景

| 场景 | 如何使用 | 实际行为 |
| --- | --- | --- |
| 日常聊天 | 点击露娜，直接在气泡输入 | 半透明对话；普通闲聊单次 LLM 请求；支持更换服务和模型 |
| 请求电脑操作 | 如“帮我检查开机自启” | 交接本机 Codex，显示进行状态及真实结果；任务目录写权限有限 |
| 屏幕陪伴 | 开启屏幕录制权限及陪伴 | 约每 3 分钟本地 OCR 前台窗口，结合实际文字吐槽；支持娱乐和工作场景 |
| 看书与喝茶 | 开启小世界 | 联网取得青空文库《夢十夜》、日本茶资料的正文节选；保留标题、范围、短引文、网址和时间；LLM 生成感想 |
| 生活动作 | 小世界自动运行 | 走动、看鼠标、拖拽落地、翻书、喝茶、吃饭、靠近撒娇；动作不代表现实世界行为 |
| 抽签 | 桌宠菜单抽签 | 摇签动作，五种结果，同一天保持一致；“凶”配哭丧表情；固定语音素材见限制 |
| 天气 | 固定城市或系统定位 | 城市级天气、相关表情与语音；数据来自 Open-Meteo，不是官方灾害预警 |
| 休息吃饭 | 提醒设置 | 午餐、晚餐、连续使用休息提醒；可延后或跳过 |
| 专注及文字工具 | 管家面板 | 专注计时、中日互译、日语润色、摘要、计划、研究辅助和指标解释 |
| 电脑照看 | 开启照看、调整红线 | 周期采样 CPU、磁盘及系统内存压力；持续异常才警告；操作结果与复查分开记录 |
| 可恢复清理 | 扫描后选择条目 | 避开活跃应用及受保护目录；移到恢复区，不覆盖恢复目标 |

看书时只声称读到已取得的节选，不编造整本阅读经历。模型失败时保留原文出处并标注“感想未生成”。用户聊天时不新发起生活规划；已开始的请求可能仍等待服务端完成。

屏幕吐槽尝试播放日语并显示对应中文字幕；普通对话语音有概率和间隔控制。静音、锁屏、正在播放或严重内存压力会限制播放。报告保持实色背景便于阅读，对话气泡半透明。

## 1.8 的入口整理

桌面点击露娜直接聊天，旁边的 `📖` 是独立读书手记；有新感想时变成 `📖✦`，搭配实际翻书及分享表情。手记列出每次阅读的感想、节选范围、原文短引文和来源，不再混入自主生活流水。

记忆与任务位于“更多与设置 → 手记与记忆”的二级入口。可直接说“记住：我喜欢简洁回答”“添加任务：核对这篇论文”，也可在手记窗口增改删。任务状态有待办、进行中和完成，不会因为添加任务就冒称执行完毕。

聊天支持问天气、查电量或磁盘空间，以及“联网搜索……”等日常查询；由普通 LLM 与本机 Python 工具协作，不走 Codex。搜索当前使用 Bing RSS 摘要，回答不能冒充读过整篇网页；服务可能限流或改变格式。天气默认查询所配置城市，不会把该城市的预报当作其他城市。

“打开天气／日历／计算器／提醒事项／备忘录”可直接请求打开这些系统应用。低难度任务不自动交接 Codex；只有高复杂度的编程、修复、安装或批量操作经判断后交接，或用户明确指定 Codex。

上下文、日志清理和运行维护没有独立界面按钮。后台每约 15 分钟做一次轻量维护，工具记录保留 7 天、最多 100 条；工具参数不会出现在聊天里。
